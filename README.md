# Розумний кошик — система розрахунку вартості покупок

## 1. Назва та призначення програми

**«Розумний кошик»** — консольна програма мовою Python для розрахунку вартості покупки. Користувач вводить товари, їхні ціни та кількість, а програма обчислює загальну суму, знижку й остаточну вартість замовлення.

## 2. Основні можливості

- Введення імені покупця.
- Додавання від 1 до 20 різних товарів.
- Введення ціни та кількості кожного товару.
- Розрахунок вартості кожної позиції та всього замовлення.
- Знижка 10%, якщо сума покупки становить не менше 1700 грн.
- Додаткова знижка 5% для власника VIP-картки.
- Вибір способу оплати.
- Перевірка введених числових даних.
- Виведення підсумкового чека.

## 3. Використані технології

- Python 3.10 або новіша версія.

## 5. Інструкція із запуску

1. Встановити Python версії 3.10 або новішої.
2. Завантажити або клонувати цей репозиторій.
3. Відкрити папку проєкту в терміналі.
4. Запустити команду:

```bash
python main.py
```

У Windows також можна використати:

```bash
py main.py
```
